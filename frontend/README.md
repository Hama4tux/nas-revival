# Frontend scope

No application or package dependencies are scaffolded yet. React/TypeScript/Vite is a candidate workstation build stack, producing static assets only. See [UI requirements](../docs/architecture/technology-selection.md) and [resource targets](../docs/architecture/overview.md).

Start with read-only Overview and explicit unavailable/stale/fault states. Later add Storage, Shares, Users, Services, Network, Logs and System. Use the versioned API rather than device paths or raw ubus methods. Verify phone/tablet/desktop, keyboard navigation and screen-reader labels. No external fonts, telemetry or graphs without a useful operational purpose.
